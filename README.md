# FORMA — сайт-визитка обувного магазина

Современный лендинг магазина обуви в доступном ценовом сегменте с каталогом товаров, корзиной, юридическими страницами и простой админкой для заявок и товаров.

**Адрес магазина:** г. Новочеркасск, ул. Думенко 4
**Телефон:** 8-928-775-36-93
**Режим работы:** ежедневно 10:00–21:00

## Возможности

- Лендинг: hero, преимущества, категории, «почему мы», тренды, отзывы, FAQ, финальный CTA
- Каталог товаров с фильтром по категориям и выбором размера
- Корзина с оформлением заявки (имя, телефон, комментарий)
- Политика конфиденциальности и публичная оферта
- Админка: просмотр заявок со статусами, добавление / редактирование / удаление товаров
- Полная адаптивность и плавные анимации появления

## Технологии

- React 19 + TypeScript
- Vite
- React Router
- Чистый CSS (без UI-библиотек), шрифты Syne + Outfit
- Хранение данных в `localStorage` (backend не требуется)

## Быстрый старт

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:5173`.

## Скрипты

| Команда           | Назначение                                 |
| ----------------- | ------------------------------------------ |
| `npm run dev`     | дев-сервер с горячей перезагрузкой         |
| `npm run build`   | проверка типов и production-сборка в `dist`|
| `npm run preview` | локальный просмотр production-сборки       |

## Страницы

| Маршрут    | Описание                                  |
| ---------- | ----------------------------------------- |
| `/`        | главная страница                          |
| `/cart`    | корзина и оформление заявки               |
| `/privacy` | политика конфиденциальности               |
| `/offer`   | публичная оферта                          |
| `/admin`   | админка (заявки и управление товарами)    |

Пароль админки задаётся в `src/types.ts` (`STORE.adminPassword`), по умолчанию — `forma2024`. Сессия входа хранится в `sessionStorage`.

## Структура проекта

```
src/
├── components/     # блоки лендинга, шапка, футер, каталог
├── pages/          # страницы: главная, корзина, документы, админка
├── context/        # StoreContext — товары, корзина, заявки
├── hooks/          # useInView — анимации появления
├── lib/            # storage.ts — работа с localStorage
├── data.ts         # контент лендинга (тексты, изображения)
├── types.ts        # типы и контакты магазина (STORE)
├── App.tsx         # маршрутизация
└── main.tsx        # точка входа
```

## Хранение данных

Товары, корзина и заявки хранятся в `localStorage` браузера — это решение для сайта-визитки без сервера. Заявки видны в админке только в том браузере, где были оформлены. Для реальных онлайн-заказов с разных устройств потребуется подключить backend (или сервис вроде Telegram-бота / Google Sheets для приёма заявок).

## Деплой

Проект собирается в статические файлы и разворачивается на любом статическом хостинге (Netlify, Vercel, GitHub Pages, обычный хостинг):

```bash
npm run build
```

Содержимое папки `dist` загрузите на хостинг.

### GitHub Pages

Сайт: `https://asyamendesz-jpg.github.io/shoe-store-s-business-card-website/`

**Важно:** на хостинг нужно заливать собранный сайт с папкой `assets/`. Если залить только `index.html`, а JS/CSS положить в корень репозитория — страница останется на «Загрузка сайта…».

#### Вариант A — папка `docs` (уже собрана в проекте)

1. Запушьте репозиторий на GitHub (включая папку `docs/`).
2. GitHub → **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: `main`, folder: **/docs** → Save.
5. Подождите 1–2 минуты и обновите сайт.

Пересборка `docs` локально:

```bash
npm run build:docs
```

#### Вариант B — GitHub Actions

После пуша в `main` workflow `.github/workflows/deploy.yml` соберёт сайт сам.  
В **Settings → Pages** выберите Source: **GitHub Actions**.
